A Host you can see and control

Connect accounts, check status, and shape the TV display.

Both Hosts provide the same essential account and Apple TV controls in an interface designed for their screen.

After installation

Pair in a few minutes.

  1. Open LoungeFeed Host.
    Allow local-network access when macOS or iOS requests it.
  2. Connect the sources you want to watch.
    Sign in through each source's authorization experience and wait for its status to show ready.
  3. Keep Host and Apple TV on the same network.
    LoungeFeed normally discovers the Host automatically.
  4. Pair from Apple TV.
    Select the Host and enter the six-digit code shown in the Host app.

What stays on the Host

Account access remains on a device you control.

Source sessions, credentials, feed cache, and media cache stay on the Host. The paired Apple TV receives read-only, normalized data through the local LoungeFeed connection.

  • Developer ID signed and Apple-notarized Mac releases
  • iPhone releases through the App Store
  • Local pairing code
  • Cache and storage controls
  • Privacy-safe diagnostic reports
